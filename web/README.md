# 网页模块

2026-10-07：网页从 `dashboard.html` 中的整页 JSX 拆分为模块源码，界面保留原设计的单页综合看板，不设置模块导航。主要面向 iPad 与 Mac 的宽屏使用；`/tasks`、本地 `/`、`/dashboard.html` 入口沿用原有方式。此记录是源码变更，不表示线上已发布。

## 目录职责

| 位置 | 职责 |
|---|---|
| `index.html` | 页面外壳、React/Tailwind CDN 和构建占位符 |
| `src/main.jsx` | 登录判断与 React 挂载；沿用 `dx_auth_token` |
| `src/app/` | 单页工作台外壳、DashboardPage 看板组合、弹窗与前台刷新生命周期 |
| `src/core/` | 请求队列、鉴权、缓存、云端版本检查、任务快照控制器 |
| `src/features/tasks/` | 看板聚焦任务、每日/本周/长期计划、表单、详情及分类模型 |
| `src/features/diary/` | 卡片内日记、展开编辑器、历史日期、草稿仓库、保存与冲突控制器 |
| `src/features/reading/` | 学习书籍编辑、微信读书书架/笔记/热力图、阅读模型与写入控制器 |
| `src/shared/`、`src/styles.css` | 通用界面组件、`theme.json` 共享配色与样式 |
| `scripts/build.cjs` | esbuild 编译模块并生成 `dashboard.html` |
| `dashboard.html` | 提交的构建产物；Worker 导入、本地 Python 服务读取 |
| `routes/`、`services/`、`sync/` | 原本的本地 API、存储与同步脚本 |
| `tests-js/`、`tests/` | 网页逻辑/Worker 契约检查与本地 Python 检查 |

不要直接修改 `dashboard.html`。在根目录执行：

```bash
npm --prefix worker install
npm run build
npm run test:web
npm --prefix worker test
python3 -m unittest discover -s web/tests -p 'test_*.py'
python3 web/server.py
```

构建工具复用 Worker 的 esbuild 依赖，没有新增网页独立安装目录；浏览器不再现场编译 JSX。React、Tailwind 和字体仍依赖原有 CDN，尚未改为离线资源。

## 数据与写入边界

`App` 只组合模块，不管理正文或书籍写入基线。前台进入立即读取，之后每 15 秒检查 `/api/sync-state`；版本变化、重新聚焦或上海日期变化时刷新。各模块失败保留原数据并重试，后台停止检查。

- 任务仍通过 `/api/data` 快照携带 `_base` 保存，只提交 `tasks` 和 `updates`。任务编辑不阻塞读书刷新；确认缓存不保存未提交的任务修改。
- 日记保留当前同步控制器：服务端声明 `syncVersion: 1` 时通过 `/api/diary/sync` 保存并保留原文版本；旧服务通过 `/api/diary/entry` 核对保存基线。两者携带原日期、原正文和确认时间。草稿即时保存到本机，按连接与浏览器 Tab 隔离，刷新恢复后先核对基线；成功后采用服务端回执。历史编辑、清空、05:00 跨日均保存原日期。旧接口冲突保留草稿，用户可选云端内容或核对后再次保存；自动同步接口在服务端合并或保留参与版本，可查看版本历史。错误不降级成无保护的整份日记上传。
- 学习书籍通过单条接口写入：修改只提交真正改动的字段，并携带 `_base`、`_readingWriteVersion: 1`。新增使用服务端 ID；删除核对整条原记录。失败保留表单草稿；冲突核对后继续。微信读书来源记录保持只读。
- 微信读书书架与笔记可展开全部，笔记支持搜索；选中笔记从当前数据派生，来源更新不会停留在旧正文。阅读日期使用上海自然日，日记采用上海 05:00 分界。

本地 Python 已提供受进程内锁保护的按日期日记保存，仍只写本地 `data/`，不自动上传。它尚未提供云端的学习书籍单条接口和版本能力，网页会明确提示并保留草稿；云端学习书籍写入需要支持对应能力的 Worker。任务草稿持久化和其他端一致性问题不属于这次网页日记/读书拆分。

## 2026-10-07 设计复核（未部署）

设计说明见 [网页工作台设计思路](docs/设计思路.md)。修改前先读用户原设计、来源及取舍，截图后复读检查，并记录下一轮修正；说明必须写出具体设计师 / 团队、作品、来源、借鉴理由及对应改动。

当前网页版采用左侧两列工作区、右侧一列记录区。左列为每日 / 本周 / 长期任务，中列为学习 / 微信读书书架，两列下方为宽幅笔记；右列依次为日记、阅读足迹和一则可切换摘录。顶部汇总长条已删除，不设模块导航。单层纸面、轻边界和统一内边距组织内容，细线区分同类列表。

- 今日聚焦完整管理每日待办，默认三项，更多原地展开；本周与长期各自同样展开，没有重复每日空卡。
- 学习书架和微信读书默认三本，全部入口在所属标题旁；微信读书使用同步封面，缺少或加载失败时显示书名首字。
- 日记在原地选择历史日期或展开编辑，共享原有常驻控制器和按日期保存流程。
- 笔记默认 340px 阅读区，搜索和列表 / 正文并排；月 / 年数据与热力图相邻，18 周格子随栏宽自适应。
- 最大内容外框 1560px，1440px 下左右留 36px、1024px 下留 24px。960px 起三列内容起点，768–959px 为两列任务 / 书架加下一排日记 / 阅读足迹。

主作品参考是苹果 iCloud 首页的宽窄内容块组合；个人设计原则参考 Jony Ive 对 iOS 7 的阐述和 Dieter Rams 的优秀设计原则。具体来源、每轮截图发现和对应实现见设计说明第 3 轮。
