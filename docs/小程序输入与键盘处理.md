# 小程序输入与键盘处理

更新：2026-10-07。用户报告 iPhone **正式版**在新增任务超过两行时整页抖动，并指出其他输入也有类似表现。正式版具体版本和微信版本尚未确认；不能把本机最新版源码当作手机正式版，更不能把开发版上传当作正式版修复生效。

## 研究依据与判断边界

- [微信官方事件定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.event.d.ts)说明键盘高度通知可能重复，相同高度应忽略；输入行变化提供高度与行数。多行输入不应随意改写用户输入。
- [微信官方窗口定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)提供物理屏幕高度、窗口上边缘和可用窗口高度，`getWindowInfo` 自基础库 2.20.1 提供。旧基础库保留 `getSystemInfoSync` 的兼容路径。
- [腾讯 TDesign 模板](https://github.com/Tencent/tdesign-miniprogram/blob/develop/packages/components/textarea/textarea.wxml)分别暴露 fixed、auto-height、adjust-position；[样式实现](https://github.com/Tencent/tdesign-miniprogram/blob/develop/packages/components/textarea/textarea.less)将留白置于外层，原生 textarea 自身 padding 为零。没有因为原生输入兼容问题而整体引入第三方组件库。
- 原作者的 iOS 复现记录：[聚焦时改变布局导致失焦](https://github.com/xiaweiss/miniprogram-bug-report/issues/172)、[自动高度初始计算问题](https://github.com/xiaweiss/miniprogram-bug-report/issues/188)、[键盘与页面滚动影响 fixed 元素](https://github.com/xiaweiss/miniprogram-bug-report/issues/121)。这些是历史复现，不能据此宣称用户当前微信版本已确认存在同一个底层缺陷。
- 微信组件网页本次浏览工具仍无法读取，以上官方开源代码和 API 定义作为可核对的一手资料；没有将第三方博客方案直接当作结论。

已确认的当前源码风险：任务和笔记采用 fixed 弹窗、CSS overflow 滚动及原生自动上推；每次输入再将正文回写到原生 value。日记聚焦时改变卡片 padding、输入区最小高度，并删除下方回顾区域。风险判断来自这些实际组合与相关复现，手机正式版根因仍需真机验证。

## 实施

1. 固定弹窗只由共享 `utils/keyboard-sheet.js` 负责避让；其中所有 textarea 和 input 关闭自身上推。按窗口在物理屏幕上的底边与键盘顶边的重叠量计算偏移，不硬编码键盘高度或 iPhone 底栏高度，不重复扣除系统已缩小的窗口。
2. 弹窗使用原生 scroll-view，测量内容的实际高度后限制在键盘上方的可用窗口内。任务、笔记复用同一逻辑；聚焦字段通过原生滚动定位，长内容仍能完整输入与读取。
3. 键盘同高度通知不重复 setData；窗口 resize 另行核对坐标。监听器在打开时注册，隐藏、取消、成功关闭、卸载时解除；注册和内容测量均带代次保护，旧回调不能移动新弹窗。
4. 原生多行控件不承担边框和 padding，外层容器负责留白。采用明确的字体和行高，任务/笔记输入区保持稳定高度并允许原生内部滚动，没有把正文裁成两行或缩短长度限制。
5. 任务/笔记用独立表单模型记录每次 native input，界面数据只负责初始显示和选项展示，避免逐字回写原生 value。提交使用最新模型，失败继续保留原文；重新回到前台时恢复完整模型到界面种子。日记仍立即持久化草稿与不可变操作，不以停止实时草稿持久化换取稳定。
6. 普通日记页面保留原生自动上推和自动增高，只移除聚焦时的几何变化：输入留白移到外层、前后最小高度一致、完成按钮和下方回顾区保留占位、字数栏稳定存在。搜索框原本为固定高度单行输入，无 auto-height 或 fixed 弹窗组合，继续使用原生普通页面处理。

## 验证与发布边界

新增 8 项有行为意义的检查，覆盖 iPhone 底栏和键盘重叠、重复高度通知、系统缩小窗口、横竖屏、旧基础库、监听和旧测量回调、后台恢复、超过两行的原文与任务选项、笔记各字段和失败重试。小程序共 81 项通过；7 个注册页面/组件 WXML 和 10 个 WXSS 原生编译通过。

微信开发工具内置 automator 接口本次返回 `wait WechatIDE authorization timeout`，因此模拟器自动化没有执行，不能称为模拟器或 iPhone 真机抖动验收通过。源码、离线检查、原生编译、开发版上传、正式发布和真机验收分别记录。1.3.11 构建标识为 `20261007-stable-iphone-input`；最终上传与 Git 回执见忽略目录 `data/archives/iphone-input-20261007/`。当前用户使用的正式版仍需微信审核发布后才能收到改动。
