## 目录与职责

```text
miniprogram/
├── src/
│   ├── app.js / app.json / app.wxss       # 原生应用、路由及全局样式
│   ├── pages/index/                      # 任务及新增／编辑表单，三类任务筛选
│   ├── pages/diary/                      # 今日写作与回顾入口
│   ├── pages/diary-history/              # 历史正文搜索、日期筛选及按月分页
│   ├── pages/diary-reader/               # 独立全文阅读，微信原生返回导航
│   ├── pages/books/                      # 书架与阅读圆环
│   ├── pages/notes/                      # 笔记／日记／长篇思想统一搜索
│   ├── components/diary-editor/          # 原生 textarea、状态与冲突操作
│   ├── styles/tokens.wxss                # 对应 Mac WorkspaceStyle 的统一视觉色值
│   ├── features/diary/                   # 原同步控制器；presentation 展示模型、library 阅读数据
│   ├── features/tasks/ / reading/        # 任务常量；model.js 阅读计算，ring.js 独立绘图
│   ├── utils/                           # 前台刷新、保存队列、搜索、视图差量
│   ├── api/index.js                      # wx.request 接口层
│   └── config.js                        # 本地凭证，忽略提交
├── scripts/build-native.cjs              # 原生文件复制与 JS 模块兼容转换
├── test/                                # 离线页面／组件／同步验证
├── dist/                                # 微信开发者工具导入目录
└── project.config.json                   # 原项目配置与 AppID
```

任务、日记、阅读与笔记直接访问原 Cloudflare Worker + TaskState；财务仍使用 Mac 本地账本。这里只迁移小程序 UI，没有修改 Mac、Worker 或生产数据。详情见 [总架构](../docs/architecture.md)。

## 构建与验证

```bash
cd miniprogram
npm ci
# 首次配置时复制 config.example.js 为 config.js，填写已有个人版 API Token。
MINIPROGRAM_BUILD_REVISION=20261007-native npm run build:weapp
npm test
# 监听原生源文件：
npm run dev:weapp
```

只编辑 `src/`，不手改 `dist/`。构建把共用 `.mjs` 模型转换为 CommonJS `.js`，转换可选链等上传器不接受的语法，复制原生 WXML／WXSS／JSON 与现有图标；没有 JSX、React 渲染或 Taro 构建。Babel 仅是构建依赖。`src/config.js`、`dist/config.js` 与临时构建目录都忽略提交。

微信开发者工具导入 `miniprogram/dist/`。服务器 request 合法域名继续为 `https://yangminggu.com`；小程序固定连接个人版 `https://yangminggu.com/tasks`，不切换 `/tasks-cloud`。

## 同步与手机交互

- 原生 `onShow` 立即读取，前台每 15 秒检查 `/api/sync-state`，`onHide/onUnload` 停止检查。
- 日记使用独立原生组件。输入立即落本机草稿，停输入 1.5 秒保存；失焦、完成、隐藏和返回补发保存。同一修改的重复离页事件只发送一次。
- 日记读取等待全局保存队列。版本基线沿本端已确认回执推进；Mac 更新触发 409 冲突并保留草稿。旧页面回执不能清掉新页面接管的草稿。
- 原文不清理空白、重复段落或分隔符；上海时区凌晨 5 点归档仍由 Worker 负责。
- 完整历史归档保存在控制器内存，`setData` 只提交今天、当前回顾和阅读中的条目。编辑时使用 `today.content` 等差量更新。
- 搜索保留笔记、日记标签排名和长篇思想三个来源，独立容错。结果分页展示，保留总数和完整正文，不把搜索索引送到视图。
- 书架来源、90% 已读完判断、最多三本在读和今日／随机笔记规则沿用迁移前行为，后续统一规则时另行修改。
